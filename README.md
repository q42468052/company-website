# 星澜科技 公司官网

一个纯静态的公司官网单页，HTML + CSS + 原生 JS，无任何构建依赖。

**在线访问**：https://q42468052.github.io/company-website/

## 包含模块

- 顶部导航（滚动毛玻璃效果、移动端汉堡菜单）
- Hero 首屏 + 数据统计（数字滚动动画）
- 产品服务（6 张卡片）
- 关于我们 + 企业文化
- 联系我们（表单为演示用途，未接后端）
- 页脚

## 自定义

直接编辑 `index.html` 中的文案即可，样式集中写在文件顶部 `<style>` 内。

## 部署

仓库开启 GitHub Pages（main 分支根目录），推送即自动发布。
